Итоговый процесс фаззинга всего сайта:
Фазинг базовых директорий, вывод в ввиде списка (с /unique) (рекурсивно)
Для http code 200:
gau для получения всех эндпоинтов - > вывод в список
фаззинг всех эндопинтов на основе этого списка (на инъекции, xss,слишком простые пароли)
Для http code 403:
Фаззинг доступа к скрытым директориям через расширения сайта (.php etc)
